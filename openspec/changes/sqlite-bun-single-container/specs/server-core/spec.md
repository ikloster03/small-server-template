## MODIFIED Requirements

### Requirement: Fail-fast валидация окружения

Сервер ДОЛЖЕН (MUST) валидировать переменные окружения (`PORT`, `DATABASE_PATH`, `LOG_LEVEL`, `AUTH_DISABLED`) через zod-схему до открытия порта. При невалидном или отсутствующем обязательном значении процесс ДОЛЖЕН (MUST) завершиться с ненулевым кодом и понятным сообщением об ошибке.

#### Scenario: Отсутствует DATABASE_PATH

- **WHEN** процесс запускается без `DATABASE_PATH`
- **THEN** процесс завершается с кодом отличным от нуля и сообщением, какая переменная невалидна
- **AND** порт не открывается

#### Scenario: Некорректный PORT

- **WHEN** `PORT=not-a-number`
- **THEN** процесс завершается с ошибкой валидации до запуска HTTP-сервера

### Requirement: HTTP-сервер на Hono

Приложение ДОЛЖНО (MUST) быть собрано на Hono и запускаться на рантайме Bun. Слушающий порт ДОЛЖЕН (MUST) открываться только после успешного завершения всех шагов инициализации (env, БД, миграции).

#### Scenario: Успешный старт

- **WHEN** env валиден, БД открыта, миграции применены
- **THEN** сервер открывает порт и логирует сообщение о готовности с номером порта
