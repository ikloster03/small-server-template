## REMOVED Requirements

### Requirement: Подключение к PostgreSQL через Drizzle

**Reason**: Шаблон нацелен на небольшие сервисы (порядка 5 пользователей), для которых отдельная СУБД — избыточный вес в развертывании; встраиваемая SQLite покрывает профиль нагрузки с запасом.

**Migration**: Подключение к файлу SQLite через Drizzle описывается новым требованием «Подключение к SQLite с WAL». Переменная `DATABASE_URL` заменяется на `DATABASE_PATH`. Развитие до PostgreSQL (если масштаб вырастет) — отдельное изменение: кодовая база изолирована за интерфейсом репозитория, меняется только слой БД.

## ADDED Requirements

### Requirement: Подключение к SQLite с WAL

Приложение ДОЛЖНО (MUST) использовать встраиваемую SQLite-базу как единственное хранилище. Путь к файлу БД ДОЛЖЕН (MUST) браться из `DATABASE_PATH`. При открытии БД ДОЛЖНЫ (MUST) включаться: режим WAL, ожидание освобождения блокировки (`busy_timeout`) и контроль внешних ключей. Операция проверки готовности ДОЛЖНА (MUST) выполнять простой запрос к БД (`select 1`). Если файл БД не может быть открыт или создан, процесс ДОЛЖЕН (MUST) завершиться с ошибкой до открытия порта.

#### Scenario: Успешное открытие

- **WHEN** старт завершается при доступном пути `DATABASE_PATH`
- **THEN** БД открывается с режимом WAL, простые запросы выполняются без ошибок

#### Scenario: Путь недоступен

- **WHEN** `DATABASE_PATH` указывает на не открываемый путь
- **THEN** процесс завершается с ошибкой до открытия порта

#### Scenario: Чтения конкурентны писателю

- **WHEN** выполняется длительная запись и одновременно приходят запросы чтения
- **THEN** чтения не блокируются записью (WAL)

## MODIFIED Requirements

### Requirement: Закрытие соединения БД при остановке

Слой БД ДОЛЖЕН (MUST) предоставлять операцию закрытия соединения с БД, вызываемую при graceful shutdown после остановки HTTP-сервера. Незавершённые операции ДОЛЖНЫ (MUST) корректно завершиться до закрытия файла БД.

#### Scenario: Остановка сервера

- **WHEN** выполняется graceful shutdown
- **THEN** соединение с БД закрывается после остановки HTTP-сервера
