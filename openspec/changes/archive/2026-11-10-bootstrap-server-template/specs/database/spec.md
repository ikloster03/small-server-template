## ADDED Requirements

### Requirement: Подключение к PostgreSQL через Drizzle

Приложение ДОЛЖНО (MUST) подключаться к PostgreSQL через Drizzle ORM на драйвере postgres.js с пулом соединений. Параметры подключения ДОЛЖНЫ (MUST) браться из `DATABASE_URL`.

#### Scenario: Успешное подключение

- **WHEN** старт завершается при доступной БД
- **THEN** пул создаётся и простые запросы выполняются без ошибок

#### Scenario: БД недоступна при старте

- **WHEN** `DATABASE_URL` указывает на недоступную БД
- **THEN** процесс завершается с ошибкой до открытия порта

### Requirement: Миграции применяются при старте до открытия порта

Миграции Drizzle ДОЛЖНЫ (MUST) применяться программно при старте процесса. HTTP-порт НЕ ДОЛЖЕН (MUST NOT) открываться до успешного завершения миграций. Файлы миграций ДОЛЖНЫ (MUST) поставляться в контейнере.

#### Scenario: Первое применение миграций

- **WHEN** сервер стартует на пустой БД
- **THEN** миграции применяются полностью, затем открывается порт

#### Scenario: Повторный старт

- **WHEN** сервер стартует на БД с уже применёнными миграциями
- **THEN** миграции не применяются повторно, сервер стартует штатно

#### Scenario: Ошибка миграции

- **WHEN** применение миграции завершается ошибкой
- **THEN** процесс завершается с ненулевым кодом, порт не открывается

### Requirement: Генерация миграций drizzle-kit

Проект ДОЛЖЕН (MUST) содержать `drizzle.config.ts` и npm-скрипт генерации миграций из схемы в `src/db/schema/`. Миграции ДОЛЖНЫ (MUST) храниться в каталоге `drizzle/`.

#### Scenario: Изменение схемы

- **WHEN** разработчик меняет схему и запускает скрипт генерации
- **THEN** в `drizzle/` появляется новый файл миграции

### Requirement: Закрытие пула при остановке

Слой БД ДОЛЖЕН (MUST) предоставлять операцию закрытия пула соединений, вызываемую при graceful shutdown после остановки HTTP-сервера.

#### Scenario: Остановка сервера

- **WHEN** выполняется graceful shutdown
- **THEN** пул соединений закрывается после остановки HTTP-сервера
