## ADDED Requirements

### Requirement: MCP-эндпоинт по Streamable HTTP

Сервер ДОЛЖЕН (MUST) предоставлять MCP-эндпоинт по транспорту Streamable HTTP поверх того же Hono-приложения (один процесс, один контейнер). Эндпоинт ДОЛЖЕН (MUST) работать в stateless-режиме без привязки сессии к инстансу.

#### Scenario: Подключение MCP-клиента

- **WHEN** MCP-клиент подключается к `/mcp` по Streamable HTTP с валидным токеном
- **THEN** сервер отвечает согласно протоколу MCP и отдаёт список инструментов

### Requirement: MCP требует bearer-токен

MCP-эндпоинт ДОЛЖЕН (MUST) быть защищён bearer-middleware: запросы без валидного токена ДОЛЖНЫ (MUST) отклоняться с `401`.

#### Scenario: MCP без токена

- **WHEN** запрос к `/mcp` выполняется без Authorization
- **THEN** ответ `401`, инициализация MCP не происходит

### Requirement: Транспорт-агностичная регистратура инструментов

Инструменты ДОЛЖНЫ (MUST) описываться в реестре независимо от транспорта: имя, описание, zod-схема входа, обработчик. Регистратор ДОЛЖЕН (MUST) подключать инструменты из реестра в MCP-сервер. Добавление инструмента НЕ ДОЛЖНО (MUST NOT) требовать знания о транспорте.

#### Scenario: Добавление инструмента

- **WHEN** в реестр добавлен новый элемент
- **THEN** инструмент появляется в списке инструментов MCP без других правок кода

### Requirement: Пример инструмента

Шаблон ДОЛЖЕН (MUST) поставляться с одним работающим примером инструмента, достаточным для проверки MCP-клиентом.

#### Scenario: Вызов примера инструмента

- **WHEN** клиент вызывает пример инструмента с корректными аргументами
- **THEN** инструмент возвращает ожидаемый результат

### Requirement: Отключение MCP-модуля одной строкой

Отключение MCP-модуля ДОЛЖНО (MUST) выполняться правкой одной строки в композиционном файле (`src/app.ts`) и НЕ ДОЛЖНО (MUST NOT) ломать запуск сервера: `/health`, `/ready`, API и Scalar UI продолжают работать, обращение к `/mcp` возвращает `404`.

#### Scenario: MCP отключён

- **WHEN** строка регистрации MCP-модуля удалена или закомментирована и сервер перезапущен
- **THEN** сервер стартует штатно, `/mcp` отвечает `404`, остальные маршруты работают

#### Scenario: MCP включён

- **WHEN** строка регистрации MCP-модуля присутствует
- **THEN** `/mcp` работает согласно протоколу MCP
